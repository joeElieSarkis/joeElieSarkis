## Featured Projects

### SignMatic - Real-Time ASL Recognition and Translation

Real-time American Sign Language recognition and translation system developed as my master's thesis.

SignMatic uses MediaPipe Holistic keypoints, sequence-based deep learning, and a compact Transformer model deployed on a Jetson Orin Nano using ONNX/TensorRT optimization. The system recognizes 50 ASL words plus an Idle class and provides bilingual English/Arabic text with offline speech output.

**Tech:** Python, MediaPipe, Deep Learning, Transformers, ONNX, TensorRT, Jetson Orin Nano, OpenCV

**Repository:** https://github.com/joeElieSarkis/signmatic-asl-realtime-recognition  
**Dataset:** https://www.kaggle.com/datasets/joesarkis/signmatic-asl-keypoint-dataset-50-words-and-idle

### NomadScholar AI - Bilingual Multimodal RAG Assistant

Bilingual multimodal Retrieval-Augmented Generation (RAG) assistant for scholarship and university applications, developed as the capstone project for my Large Language Models course.

NomadScholar AI supports English and Arabic conversations, retrieves grounded answers from curated official sources, processes images and PDFs, displays sources, maintains conversation context, and generates structured application checklists.

**Tech:** RAG, LangChain, ChromaDB, Gemini, Hugging Face Multilingual Embeddings, FastAPI, React, EasyOCR, PyPDF, Pydantic

**Repository:** https://github.com/joeElieSarkis/nomadscholar-rag-assistant
